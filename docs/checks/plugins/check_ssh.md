## Usage

```Usage:
  check_tcp [OPTIONS]

Application Options:
      --service=              Service name, for example ftp, smtp, pop, or imap
  -H, --hostname=             Host name or IP address
  -4, --ipv4                  Resolve and connect using IPv4 only
  -6, --ipv6                  Resolve and connect using IPv6 only
  -p, --port=                 Port number
  -s, --send=                 String to send to the server
  -e, --expect-pattern=       Regular expression to match in the server response
  -q, --quit=                 String to send to the server to close the connection cleanly
  -S, --ssl                   Use SSL for the connection.
  -U, --unix-sock=            Unix Domain Socket
      --no-check-certificate  Do not check certificate
  -t, --timeout=              Seconds before connection times out (default: 10)
  -m, --maxbytes=             If the received bytes exceed this number, close the connection
  -d, --delay=                Seconds to wait after sending the string before polling for a response
  -w, --warning=              Response time to result in warning status (seconds)
  -c, --critical=             Response time to result in critical status (seconds) (default: 10)
  -E, --escape                Allow \n, \r, \t or \ in the send or quit string. Put this option before send or quit. By
                              default, send adds nothing and quit appends \r\n
  -W, --error-warning         On an unexpected error, return warning instead of the default critical status. If the
                              request succeeds, the -c option takes priority.
  -C, --expect-closed         Check that the port/unixsock is closed. If closed, return OK. If open, follow the
                              ErrWarning flag. Checks only the connection.
  -v, --verbose               Log the actions taken in verbose mode.

Help Options:
  -h, --help                  Show this help message
```

## Examples

### Default Check

    check_ssh github.com
    SSH OK - 0.234 seconds response time on github.com port 22 [SSH-2.0-8ad108e] | time=0.234029s;;;0.000000;10.000000

    check_ssh --hostname github.com --warning 1
