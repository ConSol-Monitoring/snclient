## Argument Defaults

| Argument      | Default Value                                                        |
| ------------- | -------------------------------------------------------------------- |
| filter        | enabled = true                                                       |
| warning       | exit_code != 0                                                       |
| critical      | exit_code < 0                                                        |
| empty-state   | 3 (UNKNOWN)                                                          |
| empty-syntax  | %(status) - No tasks found                                           |
| top-syntax    | %(status) - %(problem_list)                                          |
| ok-syntax     | %(status) - All tasks are ok                                         |
| detail-syntax | %(uri_clean) (%(most_recent_run_time:date)) exited with %(exit_code) |

## Check Specific Arguments

| Argument  | Description                                                                                               |
| --------- | --------------------------------------------------------------------------------------------------------- |
| folder    | Folder that contains the scheduled task. Matches this folder exactly unless recursive is enabled. Default: '\' |
| hidden    | Include hidden tasks. Default: 'false'                                                                    |
| recursive | Search subfolders of the specified folder for scheduled tasks. Default: 'true'                            |
| timezone  | Set the timezone for time metrics (default is local time)                                                 |
| title     | Title of the scheduled task to check. Default: '\*'                                                       |
