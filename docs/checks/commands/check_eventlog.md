Checks Windows event log entries.

This check wraps the following WMI query:

    SELECT
        ComputerName,
        LogFile,
        Category,
        EventCode,
        EventIdentifier,
        EventType,
        Message,
        SourceName,
        Type,
        TimeWritten,
        TimeGenerated
    FROM
        Win32_NTLogEvent

See the [field descriptions](https://learn.microsoft.com/en-us/previous-versions/windows/desktop/eventlogprov/win32-ntlogevent).

When possible, SNClient adds filter conditions on id, level and source (or provider) to the WMI query's WHERE clause.
SNClient still applies the filter to the returned events.

## Argument Defaults

| Argument      | Default Value                                   |
| ------------- | ----------------------------------------------- |
| filter        | level in ('warning', 'error', 'critical')       |
| warning       | level = 'warning' or problem_count > 0          |
| critical      | level in ('error', 'critical')                  |
| empty-state   | 0 (OK)                                          |
| empty-syntax  | %(status) - No entries found                    |
| top-syntax    | %(status) - %(count) message(s) %(problem_list) |
| ok-syntax     | %(status) - Event log seems fine                |
| detail-syntax | %(file) %(source) (%(message))                  |

## Check Specific Arguments

| Argument         | Description                                                                                        |
| ---------------- | -------------------------------------------------------------------------------------------------- |
| event-codes      | Event codes to query. SNClient combines comma-separated values with OR. Valid range: 0-65535. You can repeat this option. |
| file             | File to read. Repeat this option to check multiple files.                                          |
| log              | Alias for file                                                                                     |
| scan-range       | Time range to search for messages (default is 24h)                                                 |
| timezone         | Set the timezone for time metrics (default is local time)                                          |
| truncate-message | Maximum length of each event log message                                                           |
| unique           | Alias for unique-index                                                                             |
| unique-index     | Fields that identify unique events. Set to 0 to disable. Default is "%(log)-%(source)-%(id)"       |

## Attributes

### Filter Keywords

Use these attributes in filters and thresholds, along with the default attributes:

| Attribute       | Description                                         |
| --------------- | --------------------------------------------------- |
| computer        | Which computer generated the message (ComputerName) |
| file            | The logfile name                                    |
| log             | Alias for file                                      |
| id              | Eventlog id (EventCode)                             |
| eventidentifier | Event identifier (EventIdentifier)                  |
| level           | Severity level (lowercase Type)                     |
| message         | The message as a string                             |
| source          | The source system (SourceName)                      |
| provider        | Alias for source                                    |
| written         | Time of the message being written (TimeWritten)     |

## Examples

### Default Check

    check_eventlog
    OK - Event log seems fine

    Return all events. By default, the check returns only unique events:

    check_eventlog "detail-syntax=%(id) %(uniqueindex)" "unique-index=0"
    WARNING - 4 message(s) warning(10010 Application-Microsoft-Windows-RestartManager-10010, 10016 System-Microsoft-Windows-DistributedCOM-10016, 6155 System-LsaSrv-6155, 6147 System-LsaSrv-6147)
